## 3. Hallazgos confirmados

### 3.1 GTM está instalado directamente en el theme

El contenedor `GTM-TTT6HMPN` está insertado manualmente en `layout/theme.liquid`:

- Script principal en el `<head>`.
- Iframe `noscript` al comienzo del `<body>`.

La exportación publicada confirma que el contenedor contiene una sola etiqueta:

| Campo | Valor |
| --- | --- |
| Nombre | `GA4 Config - Web` |
| Tipo técnico | `googtag` |
| ID | `G-PSM69XC45C` |
| Activador | Built-in **All Pages** (`2147479573`) |
| Frecuencia | Una vez por evento |
| Consentimiento adicional en GTM | `NOT_SET` |

No contiene etiquetas de ecommerce, Google Ads, Meta, Clarity u otras plataformas. Tampoco contiene variables personalizadas ni activadores personalizados.

### 3.2 GA4 presenta una duplicación observable de `page_view`

En una carga de la home se observaron dos solicitudes `page_view` dirigidas al mismo ID `G-PSM69XC45C`:

1. Un `page_view` general.
2. Otro `page_view` con el parámetro `shopify_event_name=page_viewed`.

La exportación confirma la primera ruta: la única etiqueta de GTM carga `G-PSM69XC45C` en todas las páginas. La captura de Shopify confirma la segunda: **Google & YouTube** tiene activos sus píxeles Web y Servidor. Por tanto, la duplicación de instalación y de `page_view` queda atribuida.

El reporte Lighthouse, que termina antes que la sesión de navegador extendida, alcanzó a registrar solo uno de esos eventos. La ausencia del segundo evento en una captura corta no descarta la duplicación.

### 3.3 Meta no está demostrado como duplicado

La home mostró un solo `PageView` para `626755473530641`, identificado como `shopify_web_pixel`. No se encontró una segunda señal equivalente en esta revisión.

El JSON confirma que GTM no contiene etiquetas de Meta. Se recomienda conservar **Facebook & Instagram**, que además muestra cobertura Web y Servidor en estado Optimizado.

### 3.4 Clarity no está demostrado como duplicado

Se observó una sola cadena normal de carga:

1. Loader de la app con `ref=shopify`.
2. Biblioteca `clarity.js`.
3. Endpoint de recolección.

El JSON confirma que GTM no contiene una etiqueta de Clarity. Se recomienda conservar la integración de **Microsoft Clarity**; la captura la muestra como Web y Siempre activo.

### 3.5 Google Ads no está instalado mediante GTM

Se observaron:

- ID `AW-16944591696`.
- Configuración y remarketing.
- Eventos `page_view` y `view_item`.
- Varias etiquetas de conversión en una ficha de producto.

La presencia de varias solicitudes no demuestra por sí sola una duplicación, porque Google Ads usa endpoints distintos para configuración, remarketing y conversiones. El JSON no contiene ninguna etiqueta de Google Ads; la medición observada proviene de la integración **Google & YouTube**. Se recomienda conservarla.

## 4. Riesgos confirmados

- La etiqueta de GTM puede inflar las vistas de página de GA4 porque el mismo ID ya se carga mediante **Google & YouTube**.
- El contenedor manual se ejecuta en todas las páginas aunque no aporta ninguna etiqueta adicional.
- La etiqueta exportada tiene `consentStatus: NOT_SET`; el script manual no queda gobernado de la misma forma que los píxeles administrados por Shopify.
- Desconectar **Google & YouTube** en lugar de retirar GTM reduciría cobertura: el canal actual tiene Web y Servidor, mientras que GTM solo contiene una etiqueta web de todas las páginas.
- No existe riesgo de perder etiquetas de Meta, Clarity o Google Ads al retirar este contenedor, porque ninguna está definida en la versión publicada de GTM.

## 6. Matriz de decisión

| Componente | Estado recomendado | Motivo |
| --- | --- | --- |
| Snippet manual `GTM-TTT6HMPN` en `theme.liquid` | Retirar | Solo carga un GA4 que ya está cubierto por Shopify |
| Tag `GA4 Config - Web` dentro de GTM | Conservar en el historial, sin cargar el contenedor | No es necesario editar o publicar GTM si se retira el snippet del theme |
| **Google & YouTube** | Conservar | Web + Servidor, ecommerce y Google Ads; es la ruta principal |
| **Facebook & Instagram** | Conservar | No está duplicado en GTM y mantiene Web + Servidor |
| **Microsoft Clarity** | Conservar | No está duplicado en GTM; se observó una sola cadena de carga |
| **Smart Pricing** | Conservar por ahora | No está duplicado en GTM; su valor comercial se revisará por separado |

## 7. Cambio recomendado

### Alternativa recomendada

Retirar de `layout/theme.liquid` únicamente:

1. El script de `GTM-TTT6HMPN` del `<head>`.
2. El iframe `noscript` de `GTM-TTT6HMPN` del `<body>`.

No modificar el contenedor de GTM y no desconectar ningún píxel de Shopify.

La alternativa fue aprobada por el propietario el 2026-09-02 y se aplicó únicamente en la copia local.

Beneficios:

- Elimina la ruta duplicada de GA4.
- Evita cargar un contenedor global que no aporta otras etiquetas.
- Conserva Google Analytics, Google Ads y ecommerce mediante **Google & YouTube**.
- Conserva Meta, Clarity y Smart Pricing.
